# 職業システム RPG PWA サンプル v0.4.0

PWAで動くRPGサンプルです。
職業変更、熟練度、上級職解放、レアアイテム転職、モンスター図鑑、ダンジョン探索、ターン制コマンドバトル、主人公レベルアップを実装しています。

- 戦闘勝利時の経験値・ゴールド獲得
- 主人公レベルアップ
- 職業熟練度の勝利連動
- ◎付きモンスターの仲間加入判定
- バージョン情報表示
- 最新版に更新ボタン

## ローカル確認

HTMLを直接開くと `fetch()` でJSONを読めない場合があります。
下記のようにローカルサーバーで確認してください。

```bat
cd rpg_job_pwa_sample
python -m http.server 8000
```

ブラウザで開きます。

```text
http://localhost:8000
```

## 注意

公開用ゲームにする場合は、作品固有の名称に見える職業名・地名・モンスター名などをオリジナル名称へ差し替えることを推奨します。
