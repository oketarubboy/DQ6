## ローカル確認

HTMLを直接開くと `fetch()` でJSONを読めない場合があります。
下記のようにローカルサーバーで確認してください。

```bat
cd rpg_job_pwa_sample
python -m http.server 8000
```

ブラウザで開きます。

```text
http://localhost:8000
```

## データファイル

```text
data/jobs.json         職業データ
data/monsters.json     モンスターデータ
data/dungeons.json     ダンジョンデータ
data/hero-levels.json  主人公経験値テーブル
data/spells.json       呪文データ
data/skills.json       特技データ
data/learn-rules.json  習得条件データ
```

## 補足

呪文・特技の取得条件は、サンプルとしてレベルアップと職業熟練度の両方に割り当てています。厳密な取得表がある場合は `data/learn-rules.json` を編集してください。

## 注意

公開用ゲームにする場合は、作品固有の名称に見える職業名・地名・モンスター名などをオリジナル名称へ差し替えることを推奨します。
