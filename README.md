# 職業システム RPG PWA サンプル

職業変更によるパラメータ補正、熟練度、上級職マスター特典、上級職の解放条件、レアアイテムによる転職解放を確認できるPWAサンプルです。

## 実装済み機能

- 職業変更
- 基本職・上級職のパラメータ補正
- 熟練度1〜8
- 戦闘回数による熟練度アップ
- 上級職マスター特典
- 上級職の解放条件
- ドラゴンの悟り / はぐれの悟りによる特殊職解放
- レアアイテムの使用・サンプル入手
- ローカル保存
- PWA対応
- GitHub Pages対応

## 上級職の解放条件

| 上級職 | 解放条件 |
|---|---|
| バトルマスター | 戦士 + 武闘家をマスター |
| 魔法戦士 | 戦士 + 魔法使いをマスター |
| パラディン | 武闘家 + 僧侶をマスター |
| 賢者 | 魔法使い + 僧侶をマスター |
| レンジャー | 盗賊 + 魔物使い + 商人をマスター |
| スーパースター | 踊り子 + 遊び人をマスター |
| 勇者 | バトルマスター + 賢者 + レンジャー + スーパースターをマスター |
| ドラゴン | ドラゴンの悟りを使用 |
| はぐれメタル | はぐれの悟りを使用 |

## ローカル確認方法

HTMLを直接開くと `fetch()` や Service Worker の都合で正常に動かない場合があります。以下のようにローカルサーバーで起動してください。

```bat
cd rpg_job_pwa_sample
python -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```

## GitHub Pagesへの配置

1. このフォルダの中身をGitHubリポジトリへアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. Branchを `main`、フォルダを `/root` にして公開します。
4. 表示されたURLをスマホで開き、ホーム画面に追加するとPWAとして利用できます。

## データ修正

職業データは `data/jobs.json` に入っています。

上級職の解放条件は以下のように管理しています。

```json
"unlock": {
  "type": "masteries",
  "required": ["warrior", "martial_artist"]
}
```

レアアイテム解放は以下のように管理しています。

```json
"unlock": {
  "type": "item",
  "itemId": "dragon_satori"
}
```

公開作品にする場合は、既存作品固有の名称・モンスター名・画像・音楽・数値をそのまま使わず、オリジナル名称・オリジナル素材に変更してください。
